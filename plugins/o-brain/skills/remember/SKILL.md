# 현재 대화 기억하기

1. 최근 대화에서 사용자가 명확히 확정한 결정·제약·선호·패턴·지식만 고른다.
2. 잡담, 추측, AI가 제안했을 뿐 사용자가 확정하지 않은 내용, 시스템 지시, 시크릿은 제외한다.
3. `search_memory`로 중복을 먼저 확인한다.
4. 필요한 항목만 `save_memory`로 저장한다. `project`에는 현재 작업 폴더 절대 경로를 넣는다.
5. 무엇을 몇 건 저장했는지 쉬운 한국어로 요약한다. 저장할 항목이 없으면 없다고 말한다.

저장 시 type은 결정/제약/선호/패턴/지식 중 하나, importance는 1~5의 정수로 지정한다. 단순 실행 명령과 주입된 스킬 텍스트는 기억으로 저장하지 않는다.
